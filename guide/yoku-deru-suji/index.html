ロト6に「よく出る数字」はあるのか

偏りは、公平な抽せんでも必ず生まれる。2,000回×2,000セットで確かめました

ロト6の情報を探すと、必ず出てくるものが2つあります。出現回数ランキングと、しばらく出ていない数字の一覧です。

たしかに表を作れば、1位の数字と最下位の数字にはっきりした差がつきます。「これだけ差があるなら、何かあるのでは」と思うのは自然なことだと思います。

そこで、絶対に公平だと分かっている抽せんで同じ表を作ってみました。数字に何の個性もない、完全な乱数です。それでどれくらいの差がつくのかが分かれば、本物の表の差をどう読めばいいかも分かります。

実験: 公平な抽せんを2,000回、それを2,000セット

1〜43から6個をでたらめに選ぶ抽せんを2,000回ぶん作り、43個の数字それぞれが何回出たかを数えます。これを1セットとして、2,000セット繰り返しました。

2,000回の抽せんで出る数字は合計12,000個。43で割ると、1つの数字あたり279.1回が期待される回数です。全部の数字がぴったり279回なら、差はゼロになります。結果はこうでした。

2,000回あたりの出現回数結果
期待される回数279.1回
1位の数字（平均）314.0回
最下位の数字（平均）245.1回
1位と最下位の差（平均）68.9回
同（2,000セット中の最小）38回
同（2,000セット中の最大）111回

どの数字にも一切の個性がないのに、1位と最下位は平均69回ちがいました。差が50回を下回ったセットは2,000のうち32セット（1.6%）だけ。40回を下回ったのは、2,000セット中わずか1セットです。

つまり「出現回数に差がある」は、抽せんが偏っている証拠には一切ならないということです。差がない方がよほど不思議で、むしろ機械を疑うべき事態になります。

本題: その1位は、次も1位なのか

ここからが本当に知りたいところです。過去の1位が次も上位に来るなら、ランキングには意味があります。来ないなら、ただの過ぎた話です。

そこで同じシミュレーションを半分に割り、前半1,000回の出現回数トップ10が、後半1,000回でもトップ10に残っているかを数えました。前半と後半は同じ乱数から作った、まったく同質の抽せんです。

前半のトップ10が後半も残った数セット数割合
0個964.8%
1個41520.8%
2個64932.5%
3個51525.8%
4個25112.6%
5個703.5%
6個40.2%
7個以上00%

平均は2.32個でした。では、前半のことを完全に無視して43個から適当に10個選んだ場合はどうなるか。10×10÷43で2.33個です。

ほぼ完全に一致しています。前半の順位を調べる作業には、次を当てる力が1ミリもない。これがシミュレーションで見えることです。

※ 実際のロト6の出現回数表を持ってきて同じことをしても、結果は同じになります。抽せん機に記憶がない以上、そうなるほかありません。

「そろそろ出るはず」も同じ話です

しばらく出ていない数字を見ると、そろそろ順番が来る気がします。これは来ません。

抽せん機は前回までの結果を覚えていないので、30回出ていない数字も昨日出た数字も、次に選ばれる確率は6/43、約13.95%で同じです。

そもそも、長い不在は珍しくもありません。確率を計算すると、どの時点を切り取ってもこうなります。

不在の長さその状態にある数字の数（平均）
直近10回で出ていない9.6個
直近20回で出ていない2.1個
直近30回で出ていない0.5個

43個のうち9個前後は、いつでも「10回以上ご無沙汰」の状態です。2,000回のシミュレーションでいちばん長かった不在は平均65.6回、最も長いセットでは107回連続で出ませんでした。公平な機械でも、ここまでは普通に起こります。

長く出ていない数字を選ぶのは構いません。ただ、それで当たりやすくなってはいない、というだけです。

ついでに、避けられがちな2つについて

「連番は出ない」「前回出た数字は続かない」もよく聞きますが、どちらも実際の数とは合いません。組み合わせを数えると、こうなります。

言われていること実際
連続した2数（例: 14と15）が含まれる54.72%
前回の当せん番号が1つ以上ふくまれる61.87%
前回から持ち越される数字の平均0.84個

連番は半分以上の回で出ます。前回の数字にいたっては6回に4回近く再登場します。どちらも「珍しいこと」ではありません。

そして、ここが前回の記事とつながるところです。連番を嫌って外す人が多いということは、連番を含む並びは選ぶ人が少ないということでもあります。当たる確率は変わりませんが、当たったときに分け合う人数は減りやすい側です。

同じ理屈で、まったく同じ6個が2回出ることもあります。2,000回のあいだにどこかで組み合わせが重複している確率は約28.0%。「一度出た並びはもう出ない」という決まりもありません。

では、過去の数字は何の役に立つのか

次回の当たりを当てる役には立ちません。役に立つのは「みんなが何を選んでいるか」を推測することだけです。

当せん金は同じ等級の当せん口数で山分けされるので、多くの人と同じ並びで当たると取り分が減ります。ここだけは、選び方で変えられます。整理するとこうです。

当たる確率どの数字を選んでも同じ。変えられない
当たったときの取り分他の買い手と被るかで変わる。変えられる

「よく出る数字」を紹介しているページは、実はこの点でだけ役に立ちます。そこに載っている数字は、それを読んだ人たちが選ぶ数字だからです。当たりやすさとは無関係ですが、被りやすさとは関係があります。

それでも、ほとんど当たりません

ロト6の1等は6,096,454通りのうち1通りです。週2回買い続けても、当たる見込みはほぼありません。

宝くじは、買ったお金のうち当せん金として戻る割合が半分に満たない遊びです。増やす手段ではなく、当たったときのことを想像して過ごす数日間を買うもの、と考えるのが実際に近いと思います。余ったお金の範囲で楽しんでください。

当せん金や購入方法の正確な情報はみずほ銀行の宝くじページでご確認ください。

よくある質問

ロト6に「よく出る数字」はありますか？

出現回数の表を作れば必ず差が出ますが、それは公平な抽せんでも生じるばらつきです。完全に公平な抽せんを2,000回おこなうシミュレーションを2,000セット試したところ、1位と最下位の差は平均68.9回、いちばん差が小さかったセットでも38回ありました。差が出ること自体は、抽せんに偏りがある証拠にはなりません。

よく出ている数字を選べば当たりやすくなりますか？

なりません。シミュレーションで前半1,000回の出現回数トップ10を調べ、それが後半1,000回でもトップ10に残っているかを数えたところ、平均2.32個でした。まったく無関係な10個を選んだときの期待値は2.33個なので、過去の順位に予測の力はありません。

しばらく出ていない数字は、そろそろ出やすいのですか？

出やすくはなりません。抽せん機は前回までの結果を覚えていないので、何回出ていなくても次回に選ばれる確率は6/43、約13.95%のままです。また、長い不在は珍しいことではありません。どの時点でも平均9.6個の数字が10回以上出ておらず、2.1個は20回以上出ていません。

連番は避けたほうがいいですか？

避ける理由はありません。ロト6の6個の中に連続した2数が含まれる組み合わせは全体の54.72%で、半分以上を占めます。むしろ連番を嫌って外す人が多いぶん、連番を含む並びは選ぶ人が少なくなり、当たったときに分け合う人数が減りやすい側です。

前回出た数字は続けて出ませんか？

よく出ます。前回の当せん番号6個のうち1つ以上が次回も出る確率は61.87%で、6回に4回近い頻度です。平均すると0.84個が続けて出る計算になります。前回の数字を機械的に外すのは、根拠がないうえに選べる範囲を狭めるだけです。

この記事の数字について

連番・前回からの持ち越し・組み合わせの重複は、ロト6の6,096,454通りから直接計算した正確な値です。出現回数に関する数字は、2,000回の抽せん × 2,000セット（合計400万回）のシミュレーション結果で、乱数の種は固定してあります。実際のロト6の当せん番号は使っていません。使う必要がないからです。

計算に使ったコードはこれだけです。

シミュレーションのコードを見る 
import numpy as np

rng = np.random.default_rng(20260912)
N, K, DRAWS, TRIALS = 43, 6, 2000, 2000

for t in range(TRIALS):
    keys = rng.random((DRAWS, N))
    idx = np.argpartition(keys, K, axis=1)[:, :K]
    hit = np.zeros((DRAWS, N), dtype=bool)
    np.put_along_axis(hit, idx, True, axis=1)

    counts = hit.sum(axis=0)          # 43個それぞれの出現回数
    spread = counts.max() - counts.min()

    c1 = hit[:DRAWS // 2].sum(axis=0)  # 前半1,000回
    c2 = hit[DRAWS // 2:].sum(axis=0)  # 後半1,000回
    a = set(np.argsort(-c1)[:10].tolist())
    b = set(np.argsort(-c2)[:10].tolist())
    overlap = len(a & b)               # 前半トップ10が後半も残った数

同じ考え方はくじ番号メーカーの中でも使っていて、「人と被りにくく」を選ぶと、この記事で説明した人が避けがちな側を含む並びを作ります。予想は一切していません。
